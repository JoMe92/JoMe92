Hi, I'm Jonas. Photography came first: I wanted to know how a camera turns light into a picture. That question took me into physics, then to cinema-camera sensors at ARRI, and from there to teaching machines to read images. Today I build computer-vision systems that run in factories, and tooling that lets coding agents do real engineering work. Senior Machine Learning Engineer at an innovation lab in Munich.

### Right now — coding agents

I use coding agents daily and maintain **[Nogging](https://github.com/JoMe92/nogging)**, a structural layer for agentic software delivery: approved specs (OpenSpec) → executable tasks (Beads) → Git evidence, with a human approval gate before autonomous execution. Agents work through issues in a sandbox on a Raspberry Pi, and I steer the whole thing from my phone — mostly to find out how far autonomy goes before review becomes the bottleneck. Works with Claude Code, Codex and Pi.

### The day job — computer vision in production

Cable-inspection model (U-Net) running at **15 sites worldwide** · end-to-end OCR pipeline with 18 % lower character error rate · TensorRT segmentation on NVIDIA Jetson at **85 ms/image** · camera-to-robot calibration on 20+ production lines. I carry the technical project responsibility for two research projects (EarlyCorr with Helmholtz-Zentrum Hereon, DeKIOps with Fraunhofer IIS), and I train customer engineers to build their own models on [Neuralyze](https://senswork.com/en/neuralyze/platform).

### How I work

- **Spec first, then small checked tasks.** Agents and humans both do their best work when the task is scoped and the acceptance test already exists.
- **Production is the bar.** A model counts once it runs on the line, not once the notebook looks good.
- **Engineers are my users.** I spend a lot of time making ML usable for people who are not ML people.
